# product-category-system (Homework)

Реализованы классы:
- `Product` (товар)
- `Category` (категория товаров)

Атрибуты класса `Category` автоматически подсчитывают количество категорий и товаров.

## Реализованный функционал

### Классы-наследники
- Созданы классы `Smartphone` и `LawnGrass`, наследующие от `Product`
- Добавлены специфичные атрибуты для каждого класса:
  - Smartphone: производительность, модель, память, цвет
  - LawnGrass: страна-производитель, срок прорастания, цвет

### Ограничения операций
1. **Сложение продуктов**:
   - Можно складывать только продукты одного типа
   - Используется строгая проверка через `type()`
   - При попытке сложить разные типы вызывается `TypeError`

2. **Добавление в категорию**:
   - Можно добавлять только объекты `Product` и его наследников
   - Проверка типов выполняется через `type()`
   - При несоответствии типа вызывается `TypeError`

### Подсчет объектов
- Автоматический подсчет количества продуктов и категорий
- Обновление счетчиков при добавлении новых объектов

## Добавленные возможности
- Абстрактный базовый класс BaseProduct
- Миксин CreationLoggerMixin для логирования создания объектов
- Классы-наследники Smartphone и LawnGrass
- Полное покрытие тестами
