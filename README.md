# product-category-system (Homework)

Реализованы классы:
- `Product` (товар)
- `Category` (категория товаров)

Атрибуты класса `Category` автоматически подсчитывают количество категорий и товаров.

## Реализованный функционал

### Обработка исключений
- При создании продукта с quantity=0 вызывается ValueError
- Метод middle_price() возвращает 0 для пустой категории
- Сохранена вся предыдущая функциональность

### Тестирование
- Покрытие тестами >75%
- Проверены все сценарии работы с исключениями
