# product-category-system (Homework)

Реализованы классы:
- `Product` (товар)
- `Category` (категория товаров)

Атрибуты класса `Category` автоматически подсчитывают количество категорий и товаров.

## Добавленные возможности
- Абстрактный базовый класс BaseProduct
- Миксин CreationLoggerMixin для логирования создания объектов
- Классы-наследники Smartphone и LawnGrass
- Полное покрытие тестами
